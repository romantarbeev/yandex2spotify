# Яндекс Музыка → Spotify

Windows-приложение на WPF и .NET 10 переносит выбранные треки из «Мне нравится» или вашего плейлиста Яндекс Музыки в Spotify. Исходники приложения находятся в `src/`. Исходный Python-процесс находится в `python_script/`.

## Запуск из исходников

Установите .NET 10 SDK для Windows и выполните из корня проекта:

```powershell
dotnet run --project .\src\Yandex2Spotify.csproj
```

Для запуска собранного `src\publish\Yandex2Spotify.exe` нужен .NET 10 Desktop Runtime. Переносите папку `src\publish` целиком. Чтобы собрать её заново, выполните:

```powershell
dotnet publish .\src\Yandex2Spotify.csproj -c Release --no-self-contained -o .\src\publish
```

## Перенос треков

1. Нажмите «Войти через Яндекс». Откройте страницу подтверждения из окна приложения, введите показанный код и разрешите доступ. Приложение получит и сохранит OAuth-токен автоматически. Если токен уже есть, вставьте его в поле ручного ввода и нажмите «Подключить». Приложение использует то же неофициальное API Яндекс Музыки, что и исходный скрипт. [Вход по коду Яндекс ID](https://yandex.ru/dev/id/doc/ru/codes/screen-code-oauth)
2. Выберите «Мне нравится» или свой плейлист и нажмите «Загрузить треки». Отметьте нужные треки. «Сохранить выбранные» выгружает их в JSON. «Открыть JSON» читает этот файл и существующий `python_script\data\likes.json` без подключения к Яндекс Музыке.
3. Нажмите «Как подключить?» в блоке Spotify, чтобы открыть инструкцию, скопировать Redirect URI и перейти в Spotify Dashboard. Укажите **Client ID** в Windows-приложении и подтвердите вход в браузере. В Development Mode у владельца приложения должен быть Spotify Premium, а импортирующий аккаунт должен иметь доступ к приложению. [Правила Development Mode Spotify](https://developer.spotify.com/documentation/web-api/tutorials/february-2026-migration-guide)
4. Выберите «Любимые треки», существующий доступный для записи плейлист или «Создать новый плейлист…» и нажмите «Перенести в Spotify».

Подключения хранятся локально с шифрованием Windows DPAPI для текущего пользователя. Во время импорта поиск учитывает ISRC, название, исполнителя и длительность. Во вкладке «Не найдено» можно сохранить список для повторной попытки. При отмене или длительном лимите Spotify можно запустить импорт снова с тем же назначением. Приложение загружает сохранённые совпадения и проверяет наличие треков в назначении перед добавлением.

## Параметры OAuth-клиента Яндекса

Для кнопки «Войти через Яндекс» скопируйте `src/yandex-oauth.example.json` в `src/yandex-oauth.local.json` и заполните `client_id` и `client_secret` клиента с доступом к API Музыки. Исходный Python-скрипт использует Android-клиент из [реализации `device_auth` в `yandex-music`](https://github.com/MarshalX/yandex-music-api/blob/main/yandex_music/_client_async/device_auth.py). Готовая сборка вне папки проекта читает этот файл из `%LOCALAPPDATA%\Yandex2Spotify`. Этот файл хранится локально и игнорируется Git. Для ввода готового токена параметры клиента не нужны.
